6 · Technical notes

For the SwiftUI build

  • Window — NSWindow with .fullSizeContentView and a transparent titlebar; traffic lights are shown/hidden along with the HUD.
  • Video — a WKWebView loading the YouTube IFrame Player (no API key needed); playback is controlled via a JS postMessage bridge.
  • OPEN QUESTION — YouTube's ToS limits background-audio hacks. Options: keep the player visible even in pill mode via a 1px-scaled view, or accept that video-off means paused audio.
  • OPEN QUESTION — live status via oEmbed / a no-key page scrape, or the YouTube Data API v3 with a user-supplied key.
  • Favorites — persisted in SwiftData or JSON under Application Support.
  • Media keys — MPNowPlayingInfoCenter + MPRemoteCommandCenter drive Now Playing and hardware keys.
  • Keep on Top — implemented with a .floating window level.
  • Menu bar — an NSStatusItem hosts the icon and popover.
  • Glass — Liquid Glass via .glassEffect() on macOS 26, with a Material fallback on earlier systems.
